# Marketing Web Reference Pack

Use this for landing pages, editorial pages, product pages, and brand-forward
web surfaces.

- Correctness: WCAG and HTML semantics for headings, landmarks, and contrast.
- Art direction: curated editorial/marketing sites as read-only inspiration.
- Typography: Practical Typography for reading rhythm and hierarchy.

Do not copy hero compositions, assets, text, animation, or brand skins. The
first viewport needs a local signature move that fits the product.
