# Mobile Card Reference Pack

Use this for responsive cards, list rows, media thumbnails, and compact mobile
summary/detail layouts.

- Correctness: WCAG reflow, target size, and focus guidance.
- Mechanics: Material lists/cards for grouping and metadata proximity.
- Polish: 60fps.design for touch-state and expansion critique.

Metadata should sit near the thing it describes. Verify 320/375/414 px layouts,
tap targets, related-item spacing, text fit, and details expansion.
