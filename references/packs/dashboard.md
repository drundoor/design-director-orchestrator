# Dashboard Reference Pack

Use this when the surface helps someone decide what needs attention next.

- Correctness: WAI/WCAG focus, contrast, and non-color-only guidance.
- Mechanics: Carbon dashboard and data-table guidance for enterprise density.
- Taste: Practical Typography for scan rhythm, hierarchy, and text roles.

Do not copy dashboard skins. Extract hierarchy rules, evidence placement, table
behavior, and typography discipline. Verify with focused chart/table/decision
area screenshots.

Avoid capsule defaults: source notes, simulated-data labels, nav counts, and
generic section labels should be plain text, source rows, squared counters, or
integrated captions. Use status tags only for concrete operational states.
