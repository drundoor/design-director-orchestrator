# Motion Reference Pack

Use this when animation is part of the design request or materially affects the
interface state.

- Platform behavior: MDN CSS animation, transition, and Web Animations docs.
- Timeline mechanics: GSAP docs when sequencing or scroll choreography matters.
- Taste: 60fps.design for motion critique and restraint.

Motion must clarify state, respect reduced motion, be interruptible where
appropriate, and avoid adding decorative delay.
